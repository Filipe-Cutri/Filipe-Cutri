## 🇧🇷 Sobre Mim

Sou bacharel em **Sistemas de Informação** com **2 anos de experiência prática** no desenvolvimento de aplicações Desktop e Backend utilizando o ecossistema Java. Tenho sólido conhecimento em:

- Desenvolvimento de **APIs REST** com Java e Spring
- **Modelagem e administração de banco de dados** com PostgreSQL e MySQL
- **Containerização** de ambientes com Docker
- **Versionamento** com Git e GitHub

Busco constantemente aprimorar minhas habilidades, contribuindo para projetos desafiadores e soluções escaláveis.

---

## 🇺🇸 About Me

I hold a bachelor's degree in **Information Systems** with **2 years of practical experience** developing desktop and backend applications using the Java ecosystem. I'm a problem-solver focused on building reliable, scalable systems.
